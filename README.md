# Hypit Video Studio

This repository hosts a minimal, no-cost GitHub Actions smoke test for the official Hypit CLI.

The first workflow installs `@hypit/hypit@0.3.2` on Ubuntu 24.04 with Node.js 22 and verifies the available commands. No model API keys or video-generation calls are used.

After installation is confirmed, the next step is to validate a real Hypit project for the 29-second potato-chip commercial 《别咬了！》.
